# 检索与筛选

## 读取品牌资料

| 字段 | 用途 |
| --- | --- |
| 品牌名称 | 确定查询对象和品牌点名的标准写法。 |
| 品牌描述 | 提取主要品类、用户、任务或场景、关键需求与限制。 |
| 品牌官网 | 提供时用于消歧、核实官方名称和产品范围。 |
| 品牌别名 | 分词检索英文名、简称等。区分别名、商品名、产品通用名和型号。 |
| 产品 / 服务 | 提供时优先按列出的产品或服务细化查询；为空时直接从描述提取。 |

品牌描述也可用一段自然语言提供。描述宽泛但已有可识别品类时，按相关品类先查并记录采用的范围。若业务范围仍无法判断，再请求补充。官网和公开资料只用于确认名称或比较范围，平台题目仍需要知乎或小红书上的证据。

## 把资料变成查询

- **产品或服务描述**：把长描述拆成「品类或俗称 + 场景或人群 + 顾虑」，一条查询只带一个主要意图。这组词通常省略品牌，采集用户怎么描述需求、怎么选、怎么买、怎么用。避开宣传语。按业务选择合适阶段，例如消费品的试用与退换、软件的迁移与协作、服务的预约与收费。
- **品牌及别名**：分别搜品牌裸词、品牌或别名加产品、品牌或别名加具体顾虑。名称与其他对象重名时加品类或产品型号。确认别名代表同一目标后再扩搜；产品通用名命中可识别对象，题干点名仍按约定品牌名判断。
- **已确认的竞品及比较问法**：先从用户提供信息或公开资料确认比较对象覆盖相近品类、目标用户或用途，再分别搜竞品名称加顾虑，并搜 `A 和 B 怎么选`、`品牌 替代方案`。只有通用替代方案时，按比较场景归类。待核实的品牌不加入竞品列表。
- 先在每平台选 6–10 个短词覆盖可用分支，再从结果里的口语、评论和薄弱场景补 4–8 个新词。根据目标量、内容新增率、登录状态和平台限制调整。每轮记录实际查询、返回量、唯一来源和入选数。达到目标且覆盖主要分支、连续两个批次没有新增相关问法，或遇到平台限制时结束。若主要分支因登录或接口问题未查到，标注未完成。

## 平台采样

- 知乎用同一轮 UUID，每批最多 4 词，每词最多 8 条。初次限流后等待再低频补查一次。问答记录用 `question_id` 或从 `/question/<id>/answer/<id>` 提取的父 ID 去重，原题链接用父问题 URL。区分问答、回答摘要与专栏。回答摘要可以帮助发现意图；不能冒充原题正文，也不能把回答中的品牌算作提问者点名。专栏的标题问句单独注明，只有确实引用真实用户原话且可核验时才称作用户提问。
- 小红书每批 1–3 词，每词最多 8 条。第一轮每词尝试打开 2–3 篇，打开时采样可见评论；第二轮优先对问法密集的词和新词加深，每词最多 5 篇。标题、摘要、正文、评论分开统计。合并同笔记时保留正文和可见评论，避免一条评论因多次命中而重复计数。
- 先验证是否对目标场景有意义，再把同义意图合并。价格、报销和哪里开属于不同意图，保留各自的问题。不同场景下的同一句“这个药多少钱”也要核实上下文。优先保留原问和可回溯证据，同一来源可支持多个不同意图。
- 逐题分别检查原问或归纳、以及题干点名。评论中的“这药”保留原话，笔记明确指向目标药或竞品时，用主题或来源上下文注明；有歧义时保持未确认。品牌、竞品可以同时出现在同一题。归纳题即使带品牌名，也从平台品牌原问统计中排除。
